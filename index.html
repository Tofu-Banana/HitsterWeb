HitsterWebiPhone setup (one time only)

On iPhone, HitsterWeb controls Spotify through Apple's Shortcuts app. Make this shortcut once:

  1. Open Shortcuts, tap +, and name the shortcut exactly HitsterWeb.
  2. Add Split Text. Tap its text and choose Shortcut Input. Set the separator to Custom and type |
  3. Add Get Item from List → First Item.
  4. Add If → Item from List is greater than 0.
  5. Inside the If, add Repeat, tap its number and choose Item from List. Inside the Repeat, add Skip Forward.
  6. Below End If, add Get Item from List → Item At Index 2, and tap its list to choose Split Text.
  7. Add Seek and set it to seek to the time from step 6 (tap the time and pick Item from List, seconds). If it won't accept it, skip this step — clips will then start from the beginning.
  8. Add Play/Pause and change it to Play.
  9. Add Get Item from List → Item At Index 3 (list: Split Text).
  10. Add Wait, tap the seconds and choose that Item from List.
  11. Add Play/Pause and change it to Pause. Done!

To test: start any song in Spotify, then tap Test. It should jump to 0:30, play 5 seconds, pause, and come back here.
